### 🧪 What I do

- Build **API test automation** with Java, REST Assured, Cucumber and JUnit 5
- Build **UI test automation** with Cypress, Cucumber and TypeScript, using page and component objects
- Write **BDD scenarios** that business people can read, linked to test case IDs in the test management tool

### 🎯 How I work

- **Readable first.** A scenario should explain the business rule without opening the code.
- **No fixed waits.** Poll for the condition, never `sleep`.
- **One test, one reason to fail.** Clear assertions, clear messages.
- **Negative tests check more than the status code.** After a rejected change, I verify the data did not change.
- **Tests are only useful if they run.** Every repository runs in CI on push and pull request.
